# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive. Harassment, discrimination and personal attacks are not
tolerated. Maintainers may remove comments, commits and contributions, or ban participants, that violate this code.

Report violations privately to the maintainer through GitHub (profile contact or a private security advisory).
All reports are reviewed and handled confidentially.
